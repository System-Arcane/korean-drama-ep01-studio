# 국제교류처 드라마 제작실

[공개 제작실 열기](https://system-arcane.github.io/korean-drama-ep01-studio/)

회차를 선택해 **대본 → 콘티 → 프리비즈 → 프롬프트** 순서로 확인합니다.

- **1화 · 오늘부터 1일** — 62컷, 한글 프롬프트 15묶음
- **2화** — 7씬, 143컷, 무음 블록 프리비즈 6분 57.8초, 한글 프롬프트 19묶음
- **3화** — 자료 등록 전

콘티에서 컷을 눌러 프리비즈를 재생하거나 컷 수정 요청을 복사할 수 있습니다.
프롬프트 탭에는 생성 묶음별 본문과 참조 자료가 있습니다.

2화 각 씬 첫 생성 묶음의 @IMAGE1에는 그 장소의 레퍼런스 시트를 반드시 첨부한다. 캐릭터시트는 @IMAGE2부터 배정하며, 오디오는 @AUDIO1부터 따로 번호를 매긴다. 장소 자료가 없으면 제작실에 준비 필요로 표시하고 해당 묶음은 자료가 준비된 뒤 생성한다. 같은 씬의 두 번째 묶음부터는 직전 실제 생성 영상 @VIDEO1의 공간과 마지막 상태를 이어받는다. 장소 시트는 공간 구조와 가구 배치에만 사용하며 프리비즈나 스타트 프레임으로 쓰지 않는다.
