# 오늘부터 1일 · 제작실

스타트 프레임은 씬별 한 장, 총 6장만 만든다. 같은 씬의 후속 SEQ에서는 첫 SEQ의 완성 이미지 파일을 그대로 재사용한다. 실사 이미지는 아직 생성 전이다.

영상 프롬프트는 네 가지 탭에서 선택한다.
- 프롬프트: 매 SEQ 공통 스타트 이미지 + 프리비즈 + 직전 생성 영상.
- 프리비즈 없이 생성: 매 SEQ 공통 스타트 이미지 + 직전 생성 영상.
- 이어 생성 · 프리비즈: 첫 SEQ만 스타트 이미지. 후속 SEQ는 프리비즈 + 직전 생성 영상.
- 이어 생성 · 프리비즈 없이: 첫 SEQ만 스타트 이미지. 후속 SEQ는 직전 생성 영상.

스타트 이미지를 첨부하는 SEQ는 앞 약 1초를 공간 확인용으로 생성하고 후반에서 제거한다. 후속 SEQ에 스타트 이미지를 첨부하지 않는 버전은 확인 화면 없이 바로 본편을 시작한다. 직전 생성 영상은 전체 또는 발췌본을 사용하며 참조 길이를 고정하지 않는다. 프리비즈 사용 시 직전 영상은 @Video2, 미사용 시 @Video1이다. 인물 이미지 번호는 각 탭 첨부 목록 순서대로 부여했다.

대사 119개와 필수 53구간은 보존한다. 본문 시간은 출력 영상 기준으로 확인 구간만큼 옮겼다. 매번 스타트 이미지를 사용하는 SEQ15는 Seedance 2.5의 현재 30초 제한에 맞춰 본편만 약 2.8% 빠르게 배정했다. 이어 생성 버전의 SEQ15는 기존 본편 시간을 유지한다. 원본 콘티·프리비즈는 변경하지 않았다.

제작실의 프리비즈 탭에서 전편 또는 액트 3개를 이어볼 수 있다. 공개 제작실은 GitHub Pages 배포본이며 로컬 수정 후 다시 배포해야 갱신된다.
