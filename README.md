[공개 제작실 열기](https://system-arcane.github.io/korean-drama-ep01-studio/)

회차를 선택해 **대본 → 콘티 → 프리비즈 → 프롬프트** 순서로 확인합니다.

- **1화 · 오늘부터 1일** — 62컷, 한글 프롬프트 15묶음
- **2화** — 7씬, 143컷, 무음 블록 프리비즈 6분 57.8초, 한글 프롬프트 19묶음
