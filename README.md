# 오늘부터 1일 · 1화 제작실

한국어 AI 드라마의 콘티·움직이는 프리비즈·생성 프롬프트 공유용 제작실.

`index.html`에서 프리비즈 / 콘티 / 프롬프트 / 스타트 프레임 / 프리비즈 없이 생성 탭을 확인할 수 있습니다. 전편·액트별 영상, 프롬프트 복사와 TXT 저장, 본문 위 첨부 참조 목록을 제공합니다.

영상용 두 버전 모두 완성 스타트 이미지를 @image1에 첨부합니다. 스타트 프레임 탭의 PNG는 구도 참조이며, 실사 스타트 이미지는 아직 생성하지 않았습니다. 같은 씬의 두 번째 SEQ부터 직전 실제 생성 영상 마지막 3초를 추가합니다. 프리비즈 사용 시 @Video2, 프리비즈 없이 생성 탭에서는 @Video1입니다. 연결 영상은 실제 생성 후 추출해야 하며 현재 미첨부로 표시합니다.

프리비즈 음성은 임시 가이드입니다. 별도 인물 음색 참조: 11명 v2 · 각 4.976초 · SEQ별 번호. 프롬프트 탭에서 WAV를 미리 듣고 다운로드할 수 있습니다.
