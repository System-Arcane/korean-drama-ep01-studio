# 국제교류처 드라마 · 연출 기준 v003

대본 → 콘티 → 프리비즈 → 프롬프트. v002의 참교육·프렌즈 관찰 근거를 유지하며, 2026-11-15 사용자 피드백을 실제 2화 편집에 적용한 기준이다.

## 대사 시간과 화면 시간을 따로 정한다

대사가 10초라고 한 화면을 10초 유지하지 않는다. 먼저 대사의 내용·발음·쉼을 보존한 연속 음성 시간을 잡고, 그 위에서 관객이 볼 사람과 대상을 정한다. 생성 묶음의 길이와 한 컷의 길이도 구분한다.

컷마다 두 가지만 먼저 적는다.

- **지금 볼 것:** 화자 / 질문을 받는 사람 / 옆에서 듣는 사람 / 시선의 대상 / 손과 소품 / 두 사람의 관계.
- **바꿀 순간:** 호명, 핵심 정보가 도착할 때, 질문의 끝을 기다릴 때, 눈길이 옮겨갈 때, 접촉이나 방향 전환이 시작될 때.

한 문장 중간에도 청자에게 화면을 줄 수 있다. 질문이 끝나기 전 청자의 얼굴로 옮겨 답을 기다리게 하거나, 답변을 말하는 사람 대신 질문자가 듣는 모습으로 받을 수 있다. 다음 대사가 시작되어도 현재 화면의 반응이 중요하면 그 화면을 유지한다.

## 2화에 적용한 예

| 장면 | 화면 편집 | 음성 연결 |
|---|---|---|
| 교실의 친구 소개 | 소개하는 두 사람 → 국적의 당사자 → 맞은편 청자 → 소개 마무리 | 트랑·루카스의 설명을 그대로 이어 듣는다. |
| 연못의 국적 질문 | 질문하는 트랑 → 듣는 준영 → 답을 듣는 트랑 | 질문과 답의 화자는 바꾸지 않는다. |
| 카페의 시선 | 시우 → 트랑 → 아델의 감탄 → 트랑의 눈길 → 준영 | 원문 감탄과 시선 변화의 순서를 지킨다. |
| 카페의 직업 설명 | 루카스의 설명 → 준영의 이해 → 형 이야기 → 준영의 반응 | 한 발화 안에서도 화면만 전환한다. |
| 브이로그의 사진 소개 | 트랑과 사진 → 가리키는 사진 속 인물 → 트랑의 얼굴 | 사진 속 인물은 움직이거나 말하지 않는다. |

이 예는 모든 장면에 반복하는 고정 순서가 아니다. 컷 길이를 일정하게 나누거나, 단독 얼굴을 기계적으로 번갈아 붙이지 않는다. 함께 보아야 할 반응은 투숏에 남긴다. 새 표정·농담·갈등·사건을 추가하지 않는다.

## 카메라를 고를 때

- 전체숏은 입장·착석·퇴장으로 공간 관계가 바뀔 때 사용한다.
- 투숏은 말과 반응, 두 사람의 거리, 서로 다른 태도를 함께 읽힐 때 사용한다.
- 가까운 얼굴은 질문을 받거나 핵심 정보를 알아듣는 순간에 사용한다.
- 어깨 너머 구도는 시선축과 상대의 존재를 연결한다. 실제 위치에서 얼굴이 가려지면 사선 상반신으로 바꾼다.
- 인서트는 원문에 있는 손·기타·식판·사진·컵의 행동이나 질문 근거를 보여줄 때 사용한다.
- 높낮이는 앉고 선 자세, 테이블과 손, 무대와 객석의 관계를 따른다. 각도 종류를 채우기 위해 바꾸지 않는다.

## 콘티·프롬프트의 공통 데이터

원문 발화는 연속 대사 목록에 한 번만 둔다. 각 컷은 그 발화의 ID와 화면 안/밖 여부를 참조한다. 컷이 바뀌어도 문장을 처음부터 반복하거나 새 쉼을 만들지 않는다. 청자에게 화자의 목소리·입 모양을 옮기지 않는다.

3화 이후에도 생성 프롬프트의 각 CUT에는 **그 구간에 들릴 어구만** 인용한다. 청자나 소품으로 앵글이 바뀌면 같은 화자의 다음 말을 ‘화면 밖 · 이어서’로 적는다. 경계에 숨이나 끝소리만 걸리면 소리 지문만 남긴다.

예를 들어 2화 식당에서 루카스의 정정은 세 화면에 나뉜다. 루카스가 보일 때 “아니요.”, 아델과 미오를 보여줄 때 “장홍 씨는 일본 사람이 아니에요.”, 장홍을 보여줄 때 “중국 사람이에요.”가 들린다. 세 컷 모두 루카스의 한 발화다.

콘티와 생성 프롬프트는 같은 컷별 어구를 사용한다. 생성 묶음 경계는 발화 중간을 피한다. 편집 속도를 높이기 위해 한국어를 급하게 말하게 하지 않는다. 실제 음성이 생성되면 단어가 도착하는 프레임을 다시 확인한다.

## 검수

1. 같은 발화 ID의 컷별 어구를 순서대로 이어 읽으면 화자·조사·어미·문장부호·필수 표현까지 승인 대사와 일치하는가.
2. 긴 설명에서 화자 외에 볼 사람이 있는지 검토했는가.
3. 전환마다 구체적인 말·시선·행동의 계기가 있는가.
4. 청자 화면에서도 원래 화자의 발화가 중단 없이 연결되는가.
5. 프리비즈의 실제 카메라가 콘티에 적힌 얼굴·손·소품을 보여주는가.
6. 컷 경계에서 좌석·시선축·소품·동작이 유지되는가.

현재 2화 v002는 143컷, 417.8초이며 기존 117개 발화의 문장과 추정 시각을 유지한다. 이 수치가 다른 회차의 컷 수·평균 길이 규칙은 아니다. 블록 프리비즈의 카메라·시간 검증과 최종 AI 영상의 표정·발음 검증은 구분한다.
